It can become quite difficult to keep PHP code structured and clean. There's a couple of good tools out there ([PHP Code Sniffer](https://pear.php.net/package/PHP_CodeSniffer/redirected), [PHP Mess Detector](https://phpmd.org/), etc) to help you manage it, but it adds a lot of overhead that can bring your productivity down. One way to keep the advantage of checking your code without taking a productivity hit, is using a build system like Jenkins.

Look at [this blog post](https://erichogue.ca/2011/05/php/continuous-integration-in-php/) to setup Jenkins and the various tools. There's also a [Jenkins PHP Template](https://jenkins-php.org/) that will help a great deal in getting things started.

I'm planning to play around with it, and post updates here about how it goes.
